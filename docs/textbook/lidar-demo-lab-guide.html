LiDAR 点云仿真实验指导书

实验概述

本实验指导书配合《LiDAR 点云仿真演示系统》主教材使用，通过实践操作帮助学生深入理解 LiDAR 仿真技术。

实验一：环境配置与基础运行

实验目的

  1. 掌握项目依赖的安装
  2. 成功运行各个版本的仿真程序
  3. 理解不同版本的特点和适用场景

实验环境

项目 要求
操作系统 Windows 10+ / macOS 10.14+ / Linux
Python 版本 3.8 或更高
内存 4GB 以上
显卡 支持 OpenGL 3.0+（Open3D 版本需要）

实验步骤

步骤 1：获取项目

# 进入项目目录
cd lidar_demo

# 查看项目文件
ls -la

步骤 2：创建虚拟环境

# 使用 Conda（推荐）
conda env create -f environment.yml
conda activate lidar_demo

# 或使用 venv
python -m venv venv
source venv/bin/activate  # macOS/Linux
# venv\Scripts\activate   # Windows

步骤 3：安装依赖

# 基础依赖（必需）
pip install numpy matplotlib

# 聚类功能（可选）
pip install scikit-learn

# Open3D 版本（可选）
pip install open3d

步骤 4：运行程序

# 1. 基础版本 - 自动移动演示
python lidar_simulation.py

# 2. 交互版本 - 键盘控制
python lidar_simulation_interactive.py

# 3. Open3D 版本 - 高性能（需要安装 Open3D）
python lidar_simulation_open3d.py

# 4. 双窗口版本
python lidar_simulation_dual.py

实验内容

5.1 理解 DBSCAN 参数

def cluster_points(points):
    clustering = DBSCAN(
        eps=2.0,        # 邻域半径 - 修改此值
        min_samples=3   # 最小样本数 - 修改此值
    ).fit(points)
    return clustering.labels_

参数说明： - eps：两个点距离小于此值时视为邻居 - min_samples：形成聚类所需的最小点数 - 标签 -1 表示噪声点（不属于任何聚类）
